# Splitwise-Application

A Python-based application to manage group expenses, track balances, and settle debts among users. This application allows users to add expenses, split them equally or based on shares/percentages, and export transaction history to a CSV file.

Features
User Management:

Add users to the group with their name and phone number.

Display all users in the group.

Expense Management:

Add expenses with a payer, amount, and description.

Split expenses equally, by shares, or by percentage among participants.

Track transaction history for each user.

Balance Tracking:

View current balances for all users.

Identify who owes money and who should receive money.

Settle Up:

Automatically calculate and suggest payments to settle debts among users.

Direct Payments:

Allow users to pay each other directly to reduce their balances.

Export Transactions:

Export all transactions to a CSV file for record-keeping.
